# MG7
## Devlog

My TreeOFBirds script used an array to store four sparrows. Also, I used a loop to check each bird. I used vector to find the distance between the player and each bird. When the player got close enough, the bird became active and popped up from the tree. This helped me learn how arrays and vectors could work together in Unity.
